# Scream Sumo — сервер-версия

2D-сумо для двух игроков в браузере. Толкаешь соперника криком в микрофон.

Стек: **Phaser 3** (рендер + физика) · **Node.js + Express + Socket.io** (сервер, WebSocket-синхронизация) · **Web Audio API** (громкость микрофона).

Почему сервер, а не P2P (как было раньше): WebRTC/PeerJS гоняет трафик напрямую между игроками через UDP, а многие провайдеры (особенно в РФ) режут или троттлят такой трафик — из-за этого были обрывы и нестабильность. Обычный WebSocket поверх HTTPS (порт 443) — тот же протокол, что у любого сайта, его никто не блокирует.

## Запуск локально (для разработки/теста на одном компьютере)

```bash
cd sumo-server
npm install
npm start
```

Открой `http://localhost:3000` — сервер сам раздаёт и клиент, и обрабатывает WebSocket-соединения на одном порту.

**Для игры с телефона в той же Wi-Fi сети:** это по-прежнему упрётся в то, что `http://` (не `https://`) не даёт доступ к микрофону на телефоне. Для реальной игры — смотри раздел деплоя ниже, это быстрее и надёжнее любых локальных танцев с сертификатами.

## Деплой на Render.com (рекомендуется, 10 минут, бесплатно, без VPN-проблем)

Даёт постоянный `https://` адрес — заходить может кто угодно, с любого устройства, без плясок с локальной сетью.

1. Залей папку `sumo-server` в свой репозиторий на GitHub (можно через сайт github.com → "Add file" → "Upload files", даже без командной строки).
2. Зайди на [render.com](https://render.com) → зарегистрируйся (можно через GitHub-аккаунт).
3. **New** → **Web Service** → выбери свой репозиторий.
4. Настройки:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
5. **Create Web Service** → подожди пару минут первого деплоя.
6. Получишь адрес вида `https://scream-sumo.onrender.com` — вот его и открывай с любого телефона.

**Важно про бесплатный тариф Render:** сервер "засыпает" после ~15 минут без обращений и первый запрос после сна грузится 30-60 секунд (сервис "просыпается"). Для игры на вечеринке — просто открой ссылку за минуту до начала, чтобы он успел проснуться. Если это будет мешать — на Render есть платный tier без засыпания ($7/мес), либо альтернативы: Railway.app, Fly.io — деплоятся так же, через GitHub.

## Как играть

1. Игрок 1 открывает адрес сервера → жмёт **"Создать"** → получает код комнаты.
2. Игрок 2 открывает тот же адрес → вводит код → жмёт **"Войти"**.
3. Оба разрешают доступ к микрофону.
4. Сумоист крутится сам по себе (виден белый "нос"-указатель направления). Крикни в микрофон в нужный момент — рванёт вперёд туда, куда смотрел. Чем громче — тем сильнее рывок.
5. Кто вылетел за золотой круг — проиграл.

## Масштабирование дальше

Текущая версия хранит комнаты в памяти одного процесса Node.js — для вечеринки/прототипа этого с большим запасом достаточно (тянет сотни одновременных комнат на самом дешёвом тарифе). Если понадобится расти дальше:

- **Горизонтальное масштабирование** (несколько инстансов сервера): понадобится Redis-адаптер для Socket.io (`@socket.io/redis-adapter`), чтобы комнаты синхронизировались между инстансами.
- **Персистентность/статистика**: подключить любую БД (Postgres на том же Render, Supabase и т.д.) — сейчас при перезапуске сервера все активные комнаты обнуляются, что для игры не критично.

Для вечера прототипирования — ничего из этого не нужно, текущая версия уже полностью рабочая и стабильная.

## Настройки баланса игры

Все константы (сила толчка, порог громкости, скорость вращения) — вверху `public/main.js`, в блоке "Настройки геймплея".
